# Veriqon-AI

**Veriqon-AI** is a **no-code AI assistant** built using **Google AI Studio** through advanced prompt engineering and AI system design. It combines intelligent web search, multimodal AI capabilities, and explainable AI features to deliver reliable, transparent, and efficient AI interactions.

## ✨ Features

* 🔍 **Intelligent Web Search**

  * Retrieves relevant and up-to-date information to provide more accurate and contextual responses.

* 🧠 **Multimodal AI Support**

  * Accepts **text, documents, images, audio, and video** as inputs for a seamless AI experience.

* 📊 **Decision Audit Mode**

  * Enhances transparency by providing:

    * **Confidence Score**
    * **Risk Analysis**
    * **Supporting Evidence**
    * **Explainable Reasoning**

* 🚀 **Smart Prompt Optimizer**

  * Automatically detects when a prompt can be improved.
  * Opens an **optimizer panel** with the user's permission.
  * Generates **two optimized prompt variations** using advanced prompt engineering techniques.
  * Allows users to compare both versions and **insert their preferred prompt into the input box with a single click** before sending it to the AI.
  * Helps users achieve higher-quality AI responses without requiring prompt engineering expertise.

* 🔗 **Chat Sharing**

  * Share conversations easily with others.

* 🗑️ **Selective Message Deletion**

  * Delete individual messages from a conversation without affecting the rest of the chat.

* 🧹 **Quick Chat Reset**

  * Typing **`clear`** in any chat tab instantly deletes the **entire conversation in that specific tab**, while leaving other chat tabs untouched.

* 🎨 **Theme Customization**

  * Supports both **automatic** and **manual** theme switching.

* 💻 **User-Centric Interface**

  * Clean, intuitive, and responsive UI designed for productivity and ease of use.

## 🎯 Goal

Veriqon-AI aims to make advanced AI interactions **more transparent, accessible, and user-friendly** by combining explainable AI, multimodal capabilities, intelligent prompt optimization, and a modern user experience—all without requiring users to write complex prompts or understand prompt engineering.
